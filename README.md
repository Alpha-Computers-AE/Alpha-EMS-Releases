# EMS-Alpha — Διαχείριση Λογαριασμών ΔΕΗ για Οργανισμούς

Επίσημη διανομή του **EMS-Alpha** της Alpha ΠΛΗΡΟΦΟΡΙΚΗ ΑΕ. Εδώ δημοσιεύονται μόνο τα
προγράμματα εγκατάστασης· ο πηγαίος κώδικας δεν είναι δημόσιος.

## Λήψη

Η τελευταία έκδοση βρίσκεται πάντα στη σελίδα
**[Releases → Latest](../../releases/latest)**. Κατεβάστε το αρχείο
`OTADEH-Setup-x.y.z.exe` και εκτελέστε το ως διαχειριστής.

## Εγκατάσταση

Το Setup προσφέρει δύο επιλογές:

- **Server + Client** — στον υπολογιστή που θα κρατά τα δεδομένα. Εγκαθιστά την
  υπηρεσία Windows, ανοίγει τη θύρα στο τοπικό δίκτυο και δημιουργεί κενή βάση.
- **Μόνο Client** — στους υπόλοιπους σταθμούς. Ζητά το όνομα ή την IP του server.

Σε **αναβάθμιση** εκτελείτε το νέο Setup πάνω στην υπάρχουσα εγκατάσταση: η βάση και οι
ρυθμίσεις δεν αγγίζονται. Τα δεδομένα ζουν στο `C:\ProgramData\Alpha\OTA-DEH`.

Πρώτη είσοδος: χρήστης `admin`, κωδικός `admin` — ζητείται αλλαγή αμέσως.

## Απαιτήσεις

Windows 10/11 ή Windows Server 2016+, 64-bit. Microsoft Edge (υπάρχει σε κάθε Windows).
Καμία άλλη εγκατάσταση — ούτε Node, ούτε βάση δεδομένων, ούτε σύνδεση στο Internet.

## Άδεια χρήσης

Το EMS-Alpha είναι εμπορικό λογισμικό. Η λειτουργία εισαγωγών και εξαγωγών απαιτεί άδεια
χρήσης δεσμευμένη στον υπολογιστή-server· η αίτηση γίνεται μέσα από την εφαρμογή
(οθόνη **Άδεια – Υποστήριξη**). Η προβολή των δεδομένων λειτουργεί πάντα.
